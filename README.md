# Hamza El Madani — Portfolio

A responsive English-language portfolio for AI / LLM engineering, RAG, LLMOps, and ROS 2 projects.

## Deploy to Vercel (no build step)

1. Create a new **public or private GitHub repository** named `hamza-portfolio`.
2. Upload **all files and folders from this directory** to the repository root (including `index.html`, `styles.css`, `script.js`, `assets/`, and the English CV PDF).
3. Go to [vercel.com/new](https://vercel.com/new), sign in, and import your GitHub repository.
4. Set **Framework Preset: Other**. Leave **Build Command** blank and **Output Directory** blank/default (the repository root is the site).
5. Click **Deploy**. Vercel will provide a `*.vercel.app` URL. Every later push to the production branch triggers an update.

## Customize

- Edit `index.html` for text, projects, contact details and links.
- Edit `styles.css` for colors and layout.
- Replace `Hamza_El_Madani_CV_English_2026.pdf` after CV updates, keeping the same filename.
- This site uses no backend, API keys, or forms. The contact button opens an email client.
- Google Fonts are loaded externally; system fonts are used as fallback.

## Pre-publish checks

- Confirm GitHub project links and benchmark numbers reflect current repositories.
- Confirm you are comfortable publishing the email address and CV contact information publicly.
- Confirm the planned December 2026 graduation timeline is still accurate.
